# Privacy Policy

GitHub CODEOWNERS Filter does not collect, store, or send any personal data.

- It runs only on `github.com` pull request pages.
- It reads the list of changed files from the page and fetches the repository's `CODEOWNERS` file from `github.com`, using your existing GitHub session. No other servers are contacted.
- Your owner selection is saved in your browser's local storage for `github.com`, so it is remembered for each repository. It never leaves your browser.
- There is no analytics, tracking, or remote code.
